# UI Redesign Notes

The frontend has been visually redesigned for a polished, modern academic SaaS experience.

## Reference direction
- RoomSync: calm spacing, editorial hierarchy, rounded surfaces
- ELVO: premium product presentation, soft gradients and focused typography
- UniSphere: structured university dashboard patterns and clear information hierarchy
- HavenStay: refined marketplace-style cards, whitespace and premium visual treatment

## What changed
- Reworked the global visual system from dark-first to a clean light SaaS interface.
- Added soft ambient gradients and a subtle grid background.
- Refreshed sidebar navigation, active states, branding, and responsive behavior.
- Refreshed the top navigation/header treatment.
- Standardized cards, borders, shadows, forms, tables, and controls.
- Added responsive behavior for tablet/mobile widths.
- Redesigned login and signup screens with a premium split-layout showcase.
- Updated browser title and metadata.

## What was intentionally preserved
- React/Vite architecture.
- Existing authentication and role-based navigation.
- Existing API service and backend integration.
- Existing timetable, conflict resolver, faculty, sections, subjects, rooms, time slots, history, analytics, and export functionality.
- Existing business logic and data flow.


## Warm no-blue theme update
- Replaced the previous indigo/violet accent system with emerald + amber.
- Removed blue-toned accent usage from the redesigned UI.
- Preserved application behavior, routing, authentication, API integration, and page structure.
